# Анализ выживаемости на Титанике 🚢

## 📊 Описание проекта

В этом проекте проводится анализ выживаемости пассажиров Титаника с использованием Python и методов анализа данных.

## 🎯 Цель

Определить ключевые факторы, влияющие на выживаемость пассажиров.

---

## 🛠 Используемые инструменты

* Python
* Pandas
* Seaborn
* Matplotlib

---

## 📂 Датасет

Данные о пассажирах Титаника (CSV файл)

---

## 📊 Основные выводы

### 1. Пол

Женщины имели значительно более высокий уровень выживаемости по сравнению с мужчинами (~74% против ~19%).
Это может указывать на приоритет эвакуации женщин.

---

### 2. Класс пассажира

Пассажиры 1-го и 2-го классов выживали чаще, чем пассажиры 3-го класса.
Это показывает влияние социального статуса на выживаемость.

---

### 3. Возраст

Дети имели более высокий шанс выживания по сравнению со взрослыми.
Это может быть связано с приоритетом спасения наиболее уязвимых пассажиров.

---

### 4. Размер семьи

Пассажиры, путешествующие в небольших семьях (1–3 человека), имели наибольшую вероятность выживания.
Одиночные пассажиры и большие семьи выживали реже.
